## 🚀 What is ZingerBoost?

**ZingerBoost** is a powerful, open-source Windows utility designed for **fresh installs** and **daily optimization**. Instead of spending hours manually tweaking Windows, removing bloatware, and hunting down essential apps — ZingerBoost does it all in a few clicks.

Whether you just reinstalled Windows or want to breathe new life into your PC, ZingerBoost gives you:

| 🧹 **Debloating** | Remove 30+ pre-installed Windows apps safely |
| :--- | :--- |
| ⚡ **Performance Tweaks** | 25+ registry optimizations for speed, privacy, and gaming |
| 🔧 **Service Control** | Disable resource-heavy background services |
| 🧼 **System Cleaning** | Clear caches, temp files, logs, and browser data |
| 📦 **App Store** | Install 30+ essential apps directly via Winget — browsers, media players, game launchers, dev tools, and more |
| 🛡️ **Full Safety** | Every change is reversible with automatic snapshots |

> **Perfect for:** gamers, power users, developers, or anyone who wants a clean, fast Windows experience without the manual hassle.

### 🛡️ Safety First — Always

ZingerBoost is built with **safety as the default**:

- ✅ **100% Reversible** — Every tweak captures its state before applying. One-click restore.
- 📸 **50 Snapshots** — Keep up to 50 restore points. Roll back to any previous state.
- 📝 **Full Audit Log** — Every single operation is recorded in a local SQLite database.
- 🔒 **Zero Telemetry** — No network calls, no tracking, no data collection. Fully offline.
- 🔍 **Open Source** — MIT licensed. Audit the code yourself.
- 🛡️ **Protected Apps** — System-critical apps (Store, Calculator, Terminal, etc.) are never touched.

## 🚀 Quick Start

### Option 1: Download Pre-built Installer (Recommended)

1. Go to [**Releases**](https://github.com/YousefMohiey/ZingerBoost/releases)
2. Download `ZingerBoost_Setup.exe`
3. Run the installer — all dependencies included
4. Requires [**Visual C++ Redistributable**](https://aka.ms/vs/17/release/vc_redist.x64.exe) (one-time install if not present)

### Option 2: Build from Source

```powershell
# 1. Clone the repository
git clone https://github.com/YousefMohiey/ZingerBoost.git
cd ZingerBoost

# 2. Build the Rust backend
cargo build --release -p zingerboost_bridge

# 3. Build the Flutter frontend (requires Flutter SDK)
cd zingerboost_flutter
flutter create --platforms windows .
flutter pub get
flutter build windows
```

> **System Requirements:** Windows 10 or later, 64-bit

## 🏗️ Architecture

ZingerBoost is built with a **Rust core** and **Flutter UI** for maximum performance and a native feel.

```
ZingerBoost/
│
├── bridge/                      # Rust FFI bridge (cdylib + staticlib)
│   ├── src/lib.rs              # AppState + init_app() FFI entrypoint
│   └── src/api.rs              # 11 FFI functions returning JSON
│
├── crates/
│   ├── zb_shared/              # Types, constants, software catalog
│   ├── zb_domain/              # Tweak trait + 25 implementations
│   ├── zb_application/         # TweakEngine, SnapshotService, AuditService
│   └── zb_infrastructure/      # WinRegistry, SQLite, Winget, PDH, DebloatEngine
│
└── zingerboost_flutter/         # Flutter desktop app
    ├── lib/pages/              # Dashboard, Tweaks, Snapshots, Debloat, Software, Settings
    ├── lib/widgets/            # Reusable UI components
    └── lib/theme/              # Dark/light theme with Riverpod
```

**Tech Stack:**
- ⚙️ **Backend:** Rust (tokio, rusqlite, windows-rs)
- 🎨 **Frontend:** Flutter Desktop (Riverpod, Material 3)
- 🔗 **Bridge:** FFI (flutter_rust_bridge ready)
- 🗄️ **Database:** SQLite (local, encrypted-capable)
