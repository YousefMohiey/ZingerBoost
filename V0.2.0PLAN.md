# ZingerBoost v0.2.0 — Migration & Feature Plan

## Architecture Change: Tauri → Flutter + Rust FFI

| Layer | Old | New |
|-------|-----|-----|
| UI Framework | React 18 + TypeScript + Vite | Flutter 3.x (Dart) |
| Desktop Shell | Tauri v2 (OS WebView2) | Flutter Desktop Embedder (Skia renderer) |
| Styling | Tailwind CSS `postcss.config.cjs` | Material 3 `ThemeData` |
| State Management | Zustand + TanStack Query | Riverpod |
| Animations | Framer Motion | Flutter `Animated*` / Lottie |
| Charts | Recharts | `fl_chart` |
| IPC | `tauri::command` + `invoke()` | `flutter_rust_bridge` auto-generated FFI |
| Rust Backend | Same 4 crates — unchanged | Same 4 crates — compiled as `cdylib` |
| Bundler | `cargo tauri build` → `.msi` | `flutter build windows` → `.msix` |

**All 4 core Rust crates stay untouched.** Only `zb_app` and `src-tauri/` get replaced.

## Snapshot Fixes

### `restore_snapshot()` in `sqlite_repo.rs` — currently stub

```rust
async fn restore_snapshot(&self, id: &str) -> Result<(), SnapshotError> {
    let conn = self.conn.lock().await;
    // 1. Read all tweak records for this snapshot
    let mut stmt = conn.prepare(
        "SELECT tweak_id, snapshot_data FROM snapshot_tweaks WHERE snapshot_id = ?1"
    )?;
    let rows: Vec<(String, String)> = stmt.query_map([id], |row| {
        Ok((row.get(0)?, row.get(1)?))
    })?.collect();

    // 2. For each record, deserialize SnapshotData
    for (tweak_id, json) in rows {
        let data: SnapshotData = serde_json::from_str(&json)?;
        // 3. The caller (TweakEngine) will iterate and call revert()
        //    Store the data back in tweak_states so get_last_snapshot_data() works
        conn.execute(
            "INSERT INTO tweak_states (tweak_id, snapshot_data, updated_at)
             VALUES (?1, ?2, ?3)
             ON CONFLICT(tweak_id) DO UPDATE SET ...",
            [&tweak_id, &json, &Utc::now().to_rfc3339()],
        )?;
    }
    Ok(())
}
```

### `apply_single()` in `tweak_engine.rs` — also save a snapshot

Currently `apply_single()` calls `save_applied()` but not `save_snapshot()`. Add:
```rust
let snapshot = SystemSnapshot::new(format!("Applied tweak: {}", id));
snapshot.add_record(id.to_string(), snapshot_data.clone());
self.snapshot_service.save_snapshot(snapshot).await?;
```

### Retention policy in `sqlite_repo.rs`

After each `save_snapshot()`, run:
```sql
DELETE FROM snapshots WHERE id NOT IN (
    SELECT id FROM snapshots ORDER BY created_at DESC LIMIT 50
);
```
Also cascade-delete their `snapshot_tweaks` rows (already set up with `ON DELETE CASCADE`).

### New Engine: `DebloatEngine` (Rust)

```rust
pub struct DebloatEngine;

impl DebloatEngine {
    pub fn remove_appx_package(package_family_name: &str) -> Result<(), DebloatError> {
        // Method 1: Direct filesystem removal
        // 1. Find package path: C:\Program Files\WindowsApps\{PackageFamilyName}_*
        // 2. takeown /f "path" /r /d y
        // 3. icacls "path" /grant Administrators:F /t /q
        // 4. Remove-AppxPackage -Package (Get-AppxPackage -Name "*PackageFamilyName*").PackageFullName

        // Method 2 (fallback): DISM
        // dism /online /Remove-ProvisionedAppxPackage /PackageName:<fullname>

        // Method 3 (last resort): Delete provisioned package registry key
        // HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Appx\AppxAllUserStore\Applications\<SearchPattern>*
    }

    pub fn disable_windows_widgets() -> Result<(), DebloatError> {
        // HKLM\SOFTWARE\Policies\Microsoft\Dsh\AllowNewsAndInterests = 0
        // + uninstall "Windows Web Experience Pack" via winget
    }
}
```
